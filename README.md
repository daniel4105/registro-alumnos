# registro-alumnos
Gestión de Proyectos -> Proyecto de práctica para organizar el desarrollo de un sistema de registro de alumnos.
## Objetivo
Organizar los requisitos y las tareas de un sistema de registro de alumnos.

## Requisitos del registro
- Solicitar el nombre completo del alumno.
- Solicitar el número de control.
- Solicitar la carrera.
- No aceptar campos obligatorios vacíos.

## Definition of Done del ejercicio
Una tarea se considera terminada cuando:
- Cumple sus criterios de aceptación.
- Su resultado está guardado en el repositorio.
- El cambio fue comprobado.
- Existe evidencia del resultado.
- Su estado se actualizó en el tablero.
